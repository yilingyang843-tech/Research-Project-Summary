This project consists of two parts: a theoretical and anlysis report and a Python computational script.

**Report:** Derive the point-counting formula for elliptic curves over finite fields starting from quadratic residues and the Legendre symbol, explain its relationship with the Frobenius trace, discuss the computational results in the context of Hasse's bound, and compare the normalized trace distributions of three elliptic curves. 

**Python:** Implement both the direct enumeration method and the Legendre symbol method to compute the number of points, Frobenius traces, and normalized traces for three elliptic curves over various primes; verify consistency between the two methods, compare their computational efficiency, and analyze trace variations and distributions using visualization and descriptive statistics.
