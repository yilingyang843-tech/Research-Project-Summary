# Research Project Summary

A collection of my undergraduate research and academic projects completed during four years of study at Wenzhou-Kean University.

| Project | Relevant Fields | Materials |
| --- | --- | --- |
| **Adaptive Federated Graph Learning for Diabetes Classification** | Data Science, Biostatistics, Machine Learning, Healthcare Analytics | **Code:** Python implementation of federated graph learning and model comparison.<br>**Report:** Methodology, experiments, results, and limitations. |
| **Behavioral Factors and Depressive Symptoms** | Statistics, Biostatistics, Data Science, Public Health | **Code:** R implementation of NHANES data processing, statistical tests, multiple regression, Random Forest, and XGBoost.<br>**Report:** Research background, data sources, statistical methods, and findings. |
| **Credit Card Customer Churn Prediction** | Data Science, Statistics, Machine Learning, Financial Analytics | **Code:** Python implementation of data preprocessing, SMOTE, SVM, Random Forest, KELM, and QChOA optimization.<br>**Report:** Model methodology, parameter optimization, performance evaluation, and limitations. |
| **Elliptic Curve Point Counts over Finite Fields** | Computational Mathematics, Number Theory, Scientific Computing | **Code:** Python implementation of direct enumeration and Legendre-symbol point-counting methods.<br>**Report:** Mathematical derivation, Frobenius trace analysis, computational comparison, and results. |
| **Temperature Forecasting for Wenzhou-Kean University** | Data Science, Statistics, Time-Series Forecasting, Environmental Analytics | **Code:** Jupyter Notebook for weather-data processing, feature construction, Random Forest prediction, and Holt-Winters forecasting.<br>**Report:** Data preparation, forecasting methodology, model integration, results, and limitations. |
